# 나의 가계부

브라우저에서 바로 쓰는 개인용 가계부입니다. 서버나 설치 없이 동작합니다.

## 실행 방법

`index.html` 파일을 더블클릭해서 브라우저(크롬, 엣지, 사파리 등)로 엽니다.

## 기능

- 수입/지출 입력: 날짜, 금액, 구분(수입/지출), 카테고리, 메모
  - 지출 카테고리: 식비, 교통, 주거, 쇼핑, 기타
  - 수입 카테고리: 월급, 기타
- 월별 내역 목록 (최신순), ◀ ▶ 버튼으로 달 이동
- 내역 수정·삭제
- 월별 총수입, 총지출, 잔액 표시
- 휴대폰 화면에 맞춘 디자인

## 사용법

1. **입력:** 날짜·구분·카테고리·금액(·메모)을 넣고 **추가**를 누릅니다.
2. **달 이동:** 요약 위의 ◀ ▶ 버튼을 누릅니다. 다른 달 날짜로 입력하면 그 달로 자동 이동합니다.
3. **수정:** 목록에서 **수정**을 누르면 위쪽 폼에 값이 채워집니다. 고친 뒤 **수정 완료**를 누르고, 그만두려면 **취소**를 누릅니다.
4. **삭제:** 목록에서 **삭제**를 누르고 확인 창에서 **확인**을 누릅니다.

## 데이터 저장에 대해 (꼭 읽어 주세요)

- 데이터는 브라우저의 **localStorage**에 저장됩니다. 인터넷으로 어디에도 전송되지 않습니다.
- **브라우저마다, 기기마다 따로 저장됩니다.** 크롬에서 입력한 내역은 사파리나 휴대폰에서 보이지 않습니다.
- 브라우저의 "인터넷 사용 기록 삭제(쿠키 및 사이트 데이터)"를 하거나 시크릿 창을 닫으면 **데이터가 지워질 수 있습니다.**
- 저장된 데이터 직접 보기: F12 → Application(Firefox는 Storage) → Local storage → `household-entries`

## 파일 구조

```
index.html   화면 구조 (입력 폼, 요약, 목록)
style.css    디자인과 모바일 대응
app.js       동작 (저장, 계산, 화면 그리기, 버튼 처리)
```

### app.js 안의 구역

| 구역 | 하는 일 |
|---|---|
| 1. 상수 | 카테고리 목록, 저장 이름, 최대 금액 |
| 2. 저장/불러오기 | `loadEntries()`, `saveEntries()` |
| 3. 계산 | 월별로 고르기, 합계, 최신순 정렬 |
| 4. 화면 그리기 | `render()` → 월 표시, 요약, 목록 |
| 5. 이벤트 처리 | 추가, 수정, 삭제, 월 이동, 입력 검사 |

기본 흐름: **`entries` 배열을 바꾼다 → `saveEntries()` → `render()`**

### 자주 바꿀 만한 곳

- 카테고리 추가/변경: `app.js` 맨 위의 `CATEGORIES`
- 색상 변경: `style.css` 맨 위의 `:root` 안 색상 변수
