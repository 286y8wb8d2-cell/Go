# 나의 자산

브라우저에서 바로 쓰는 개인용 자산 관리 앱입니다. 서버나 설치 없이 동작합니다.

- **사이트 주소:** https://286y8wb8d2-cell.github.io/Go/
- 휴대폰에서는 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다.
  - 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
  - 안드로이드(크롬): ⋮ → 홈 화면에 추가
- PC에서는 `index.html`을 더블클릭해서 열어도 됩니다.

## 탭별 기능

앱을 열면 항상 **홈(대시보드)**부터 보입니다. 새로고침하면 보던 탭이 그대로 유지됩니다(주소 끝의 `#assets` 같은 표시).
휴대폰에서는 **화면을 좌우로 밀어서** 탭을 넘길 수 있습니다 (왼쪽으로 밀면 다음 탭, 오른쪽으로 밀면 이전 탭). 입력칸·옆으로 밀리는 표·자산 추이 그래프 위에서는 넘어가지 않습니다.

전체 개선 기획은 [APP_PLAN.md](APP_PLAN.md), 비트코인 탭 기획은 [BTC_PLAN.md](BTC_PLAN.md)에 있습니다.

### 홈 (대시보드)
- **최근 거래일 변동:** 티커가 있는 종목과 비트코인의 하루 등락으로 계산한 내 자산 변화
- **자산 목표:** 목표 총 자산 대비 진행률과, 지난 기록의 월평균 증가가 이어지면 언제쯤 도달하는지
- **시장 한눈에:** S&P 500 · 나스닥 · 코스피 · 원/달러 · 미국 10년 금리 · 비트코인 (값·등락·1년 추이선)
- **총 자산** 큰 숫자, 지난달 기록 대비 변화, 최근 12개월 추이선
- **자산 구성:** 자산군별 비중 막대와 금액
- **한눈에 보기:** 총 손익, 연 예상 배당, 비트코인 손익(수익률), 비트코인 비중
- **큰 종목 TOP 5:** 금융자산·비트코인을 합쳐 평가금액이 큰 순서
- "자세히" 버튼으로 해당 탭으로 이동

### 가계부
- **현황:** 순자산(자산 − 부채)이 목표까지 몇 %인지 고리로, 이번 달 월급이 어디로 가는지 막대로, 할부·대출이 끝날 때마다 여유돈이 얼마나 늘어나는지 계단으로
- **수입·지출:** 세후 월급, 매달 나가는 돈(묶음·시작/끝 달), 계산 설정(순자산 목표·물가·마지막 해·비트코인 가격 시나리오)
- **부채:** 총 부채·연 이자·가장 비싼 빚, 대출 사다리(잔액·금리·만기), 해마다 줄어드는 잔액 막대. 원리금 상환·원금균등·이자만(만기 일시상환) 세 가지 방식
- **미래:** 비트코인 가격 시나리오 3개로 순자산 길 그래프, 물가 반영 금액, 비트코인 가격별 내 손익, 순자산 목표에 필요한 비트코인 가격
- **이벤트:** 할부·대출이 끝나는 달, 만기, 반감기, 직접 넣은 일을 날짜 순서로 (다음 일은 D-day)
- 자산은 금융자산·비트코인 탭 값을 그대로 씀. 가계부 값은 이 기기에만 저장되고 백업 파일에 포함

### 금융자산
작은 탭 4개: **요약 · 추이 · 배당 · 종목**
- **티커와 자동 시세:** 종목에 티커(예: QQQ, SCHD, 005930)를 넣으면 이름·종류·현재가·배당금·지급월이 채워지고, 새 시세가 올 때마다 자동으로 바뀜 (켜고 끌 수 있음, 해외 종목은 원화로 환산)
  - 종목명이 티커나 국내 종목 이름과 같으면(QQQ, 삼성전자 등) 티커를 자동으로 연결
  - 시세는 GitHub Actions가 6시간마다 모으는 약 180개 인기 종목·ETF 목록에서 찾음 (목록에 없으면 직접 입력)
  - 배당 지급월은 배당락 기준이라 실제 입금은 몇 주 늦을 수 있음
- 종목마다 최근 거래일 등락, 52주 범위 안 위치, 1년 추이선
- **다가오는 배당:** 이번 달부터 3개월 동안 들어올 배당
- **전체 자산:** 금융자산 + 비트코인 합계, 총 손익, 자산군별 비중
- **자산 추이:** 매달 총 자산을 **자동 기록**(이번 달 기록은 자산이 바뀔 때마다 갱신), 선 그래프(누르거나 끌면 그달 값)와 기록 표
  - **지난달 기록 직접 추가·수정:** 앱을 쓰기 전 달의 자산을 넣거나 잘못된 달을 고칠 수 있음 (직접 넣은 기록은 "직접" 표시). 이번 달과 앞으로 올 달은 직접 입력할 수 없음
- **포트폴리오 요약:** 총 평가금액, 총 손익, 수익률, 종류별 비중
- **예상 배당:** 연간·월평균 배당금, 배당수익률, 세후 추정(15.4%), 배당 종목 목록
  - **월별 배당 그래프:** 1~12월 막대, 누르면 그달 들어오는 종목별 금액
- **종목 입력:** 종목명, 종류(국내주식/해외주식/ETF/채권/예적금/현금/기타), 수량, 평균 매입가, 현재가, 주당 연간 배당금
  - 예적금·현금은 수량 1, 매입가와 현재가에 잔액을 넣습니다.
  - 현재가는 직접 입력합니다. 가끔 증권 앱을 보고 **수정**으로 고쳐 주세요.
  - 배당금을 넣으면 **배당 지급월**을 고릅니다 (월배당/분기/반기/연 1회 버튼 또는 1~12월 체크). 지급월이 없는 예전 종목은 12월 지급으로 계산합니다.
- **보유 종목:** 평가금액 순, 종목별 손익·수익률·비중, 수정·삭제

### 비트코인
비트코인 탭 안에 작은 탭 6개가 있습니다: **시세 · 차트 · 블록 · 도구 · 정보 · 내 코인** (마지막으로 본 작은 탭을 기억). 기획 내용은 [BTC_PLAN.md](BTC_PLAN.md).
비트코인 탭을 보고 있을 때만 정보를 받고, 다른 탭에 있거나 앱을 내려 두면 멈춥니다. 이때 **개인 정보(보유량·금액)는 어디에도 보내지 않습니다.**

**시세**
- **실시간 시세:** 업비트·빗썸·바이낸스·코인베이스 웹소켓으로 거래가 있을 때마다 바로 바뀜 (업비트/빗썸 중 고르기). 오르면 빨강, 내리면 파랑으로 깜빡
  - 24시간 고가·저가·거래대금, 1,000원으로 살 수 있는 사토시, 다른 거래소와의 차이, **내 비트코인 지금 가치·손익** (내 코인에 BTC가 있을 때, 저장은 안 함)
  - 웹소켓이 안 되면 30초마다 일반 주소로 (빗썸, 해외: 바이낸스 → 코인게코)
- **김치 프리미엄:** 환율 기준 + USDT(테더) 기준, **거래소별 가격**(업비트·빗썸·바이낸스·코인베이스, 바이낸스 대비 프리미엄). 김프(%) = (국내 가격 ÷ 해외 가격의 원화 환산 - 1) × 100. 환율은 ExchangeRate-API → 코인게코
- **매수 vs 매도:** 거래소 체결을 실시간으로 받아 최근 1·5·15분 동안 사는 쪽과 파는 쪽 중 어느 힘이 셌는지(거래소별), 1 BTC 이상 큰 거래 목록
- **시장 지표:** 비트코인 도미넌스(코인게코), 공포·탐욕 지수, 원/달러 환율, USDT 시세
- **공포·탐욕 지수(F&G)** (alternative.me, 하루 한 번 바뀜): 반원 게이지, 어제·지난주·지난달, 최근 30일 막대
  - 0~24 극단적 공포 · 25~45 공포 · 46~54 중립 · 55~75 탐욕 · 76~100 극단적 탐욕

**차트**
- **캔들 차트:** **비트코인 첫 거래(2010년 7월)부터 오늘까지.** 일봉/주봉/월봉 × 3개월/1년/4년/전체(로그 눈금). 누르거나 끌면 시가·고가·저가·종가
  - **내 평균 매입가 선**(주황 점선)을 켜고 끌 수 있음
  - 과거 가격은 앱에 넣어 둔 기록(`btc-history.js`: Coin Metrics 하루 달러 가격 × 그날 원/달러 환율(FRED), 2026년 5월 23일까지)을 쓰고, 빗썸이 주는 기간은 빗썸 일봉으로 덮어씀. 빗썸이 안 되면 최근 1년은 코인게코
- **반감기 사이클 비교:** 반감기 날 가격을 ×1로 놓고 2012·2016·2020·지금 사이클이 며칠째에 몇 배였는지 겹쳐 봄 (로그 눈금)
- **월별 등락률:** 연도 × 월 표 (오르면 빨강, 내리면 파랑), 달마다 평균과 오른 해 비율

**블록** (mempool.space)
- **반감기:** D-day와 **실시간 카운트다운**(1초마다), 예상 날짜, 진행률, 블록 보상, 지난 반감기
- **실시간 블록** (30초마다): 채굴 대기 블록(예상)과 방금 채굴된 블록, 추천 수수료(송금 1건 원화 어림), 대기 거래 수, 다음 난이도 조정
- **해시레이트 · 난이도:** 3개월/1년/3년/전체 차트, 지금 해시레이트·난이도
- **검색:** 블록 번호·거래 ID·주소를 넣으면 mempool.space에서 열기

**도구**
- **계산기:** BTC · 사토시 · 원 · 달러를 실시간 가격으로 서로 바꿈
- **적립식 시뮬레이터:** 매일/매주/매달 같은 금액으로 샀다면 지금 얼마인지, 모은 BTC, 평균 매입가, 한 번에 샀을 때와 비교 (2010년 8월부터)
- **솔로 채굴 확률:** 내 채굴기 해시레이트로 블록을 찾을 하루·1년 확률과 평균 기다리는 시간
- **이 금액은 몇 BTC?:** 아파트 값 같은 금액이 지금과 1·2·4·8·12년 전에 몇 BTC였는지
- **BIP39 단어 목록:** 시드 문구에 쓰는 2048개 단어 찾아보기 (실제 시드 문구는 절대 입력하지 말 것)

**정보** (아래 "예비 데이터" 사용)
- **기업 보유량:** 비트코인을 가진 상장 기업 순위 (코인게코)
- **현물 ETF:** 하루 순유입 막대, 최근 5거래일 합계, ETF가 가진 비트코인 (XOOMAR 무료 데이터라 IBIT·ARKB·BITB 등 일부만)
- **M2와 비트코인:** 미국 통화량(M2)과 비트코인 가격을 같은 출발점 100으로 맞춰 비교 (FRED, Coin Metrics·코인게코)
- **출금 수수료:** 업비트·빗썸·코빗·바이낸스의 비트코인·라이트닝 출금 수수료와 원화 환산
- **거래소 사고 연표:** 널리 알려진 거래소 해킹·파산 사례 (한국·해킹·파산 골라 보기)

**예비 데이터 (GitHub Actions)**
- 브라우저에서 막혀 있거나 서버에서만 받을 수 있는 정보는 `.github/workflows/btc-data.yml`이 **6시간마다** `scripts/fetch-btc-data.mjs`를 실행해 모읍니다.
- 결과는 저장소의 **`data` 가지**(`btc-data.json`, 주식 시세는 `market-data.json`, 매번 덮어씀)에 올라가고, 앱은 `raw.githubusercontent.com`에서 읽습니다. `main` 기록에는 쌓이지 않습니다.
- 공포·탐욕 지수·도미넌스도 함께 모아 두어, 앱이 직접 못 받을 때 대신 씁니다.
- 바로 다시 모으려면 GitHub 저장소 → Actions → btc-data → Run workflow

**내 코인**
- **스택 목표:** 모으고 싶은 BTC 수량과 진행률, 남은 사토시·원화 (백업에 포함)
- 코인명, **심볼**(예: BTC), 수량(소수점 가능), 평균 매입가, 현재가, 보관처
- **시세 불러오기:** 심볼이 있는 코인의 현재가를 원화 시세로 한 번에 갱신
  - **빗썸 → 코인게코** 순서로 시도하고, 빗썸에 없는 코인만 코인게코에서 찾습니다. (업비트는 브라우저에서 바로 부르는 걸 막아 두어 쓰지 않습니다)
  - 결과 안내에 어디서 몇 개를 가져왔는지 표시됩니다. 두 곳 모두 접속이 안 되면 알림창으로 알려 줍니다.
  - 코인게코 가격은 세계 평균을 원화로 바꾼 값이라 국내 거래소 가격과 조금 다를 수 있습니다.
  - 시세 서비스에는 코인 심볼만 보내고 보유량·금액은 보내지 않습니다.
  - 심볼 칸이 비어 있으면 코인명 속 영어 대문자(예: "이더리움 ETH"의 ETH)를 씁니다.
- 총 평가금액, 손익, 수익률, 코인별 비중 (8번째 코인부터는 "기타"로 묶음)

### 시나리오
작은 탭 2개: **가격 변동 · 미래 적립**
- **실제 하락장 다시 겪어 보기:** 2008 금융위기, 2018 크립토 겨울, 2020 코로나 급락, 2022 금리 인상 (대략적인 고점 대비 하락폭)
- 미래 적립에 **목표 금액 도달까지 걸리는 시간** (비관·기본·낙관)
- **가격 변동 시나리오:** 자산군별 변동률(%)을 넣으면 총 자산이 어떻게 바뀌는지 바로 계산
  - 예시 버튼(폭락장/조정장/상승장), 자산군별 결과 표
  - **종목별로 따로 정하기:** 특정 종목·코인만 다른 변동률 (빈칸이면 자산군 값)
  - 이름을 붙여 저장하고 여러 개를 비교 (지금 자산 기준으로 다시 계산됨)
- **미래 적립 시뮬레이션:** 시작 금액 + 매월 투자금으로 N년 뒤 금액을 비관/기본/낙관 수익률로 비교
  - "현재 자산" 버튼으로 지금 총 자산을 시작 금액으로 불러올 수 있음
  - 배당 재투자 여부, 연도별 표

> 시나리오와 예상 배당은 입력한 가정으로 계산한 **추정치**입니다. 실제 수익을 보장하지 않으며 세금·수수료·물가는 대부분 반영하지 않았습니다.

## 데이터 저장과 백업 (꼭 읽어 주세요)

- 데이터는 브라우저의 **localStorage**에만 저장되고, 인터넷으로 어디에도 전송되지 않습니다. (시세·블록 정보를 받아 올 때도 내 데이터는 보내지 않음)
- **브라우저마다, 기기마다 따로 저장됩니다.** (PC와 휴대폰의 데이터는 서로 보이지 않음)
- 브라우저의 "방문 기록 및 웹사이트 데이터 지우기"를 하면 **데이터가 지워집니다.**
- 그래서 페이지 맨 아래 **데이터 백업**을 가끔 해 두세요.
  - **내보내기:** 금융자산·비트코인·시나리오·자산 기록·가계부·설정을 `household-backup-날짜.json` 파일 하나로 저장
  - **불러오기:** 그 파일을 고르면 확인 후 데이터를 되살림 (지금 데이터는 백업 내용으로 바뀜)
  - 다른 기기로 옮길 때도 같은 방법을 씁니다.
  - 30일 넘게 백업하지 않으면 빨간 글씨로 알려 줍니다.

### 코드의 기본 규칙

- **흐름:** 데이터 배열을 바꾼다 → `saveList()`로 저장 → 화면을 다시 그린다(`render…()`)
- **탭끼리 연결:** `saveList()`가 저장할 때마다 `data-saved` 신호를 보내고, 전체 자산·시나리오가 그 신호를 듣고 다시 계산합니다.
- **탭 바뀜 신호:** 탭이 바뀔 때마다 `tab-shown` 신호를 보내고, 비트코인 탭이 이 신호로 자동 갱신·실시간 연결을 켜고 끕니다. 비트코인 파일끼리는 `btc-active`, `btc-view-shown`, `btc-price-updated`, `btc-candles-updated`, `btc-network-updated` 신호를 주고받습니다.
- **이름 규칙:** 모든 JS 파일이 이름을 함께 쓰므로, 파일마다 앞에 붙이는 말을 정해 겹치지 않게 합니다.
  (`asset~`, `crypto~`, `btc~`, `networth~`, `history~`, `dash~`, `scenario~`, `sim~`, `budget~`, `backup~`)
- **각 파일 안의 순서:** 1. 상수 → 2. 저장/불러오기 → 3. 계산 → 4. 화면 그리기 → 5. 이벤트 처리 → 시작

## 고칠 때 알아 두면 좋은 것

- **자산 종류 바꾸기:** `assets.js`의 `ASSET_KINDS`와 `index.html`의 종류 `<option>` (저장용 영어 이름은 바꾸지 말 것)
- **색 바꾸기:** `style.css` 맨 위 `:root`
  - 수익/손실 색: `--up`(빨강), `--down`(파랑)
- **시나리오 예시 바꾸기:** `scenario.js`의 `SCENARIO_PRESETS`
- **CSS나 JS를 고친 뒤에는** `index.html`의 `?v=숫자`, `<html data-version>`, `version.json`의 숫자를 함께 하나씩 올려 주세요. 그래야 휴대폰에서 예전 파일 대신 새 파일을 받아 옵니다.
- `main`에 올리면 1~2분 뒤 GitHub Pages 사이트에 자동으로 반영됩니다.
