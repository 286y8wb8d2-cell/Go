# 나의 가계부

브라우저에서 바로 쓰는 개인용 가계부 + 자산 관리 앱입니다. 서버나 설치 없이 동작합니다.

- **사이트 주소:** https://286y8wb8d2-cell.github.io/Go/
- 휴대폰에서는 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다.
  - 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
  - 안드로이드(크롬): ⋮ → 홈 화면에 추가
- PC에서는 `index.html`을 더블클릭해서 열어도 됩니다.

## 탭별 기능

앱을 열면 항상 **홈(대시보드)**부터 보입니다. 새로고침하면 보던 탭이 그대로 유지됩니다(주소 끝의 `#assets` 같은 표시).
휴대폰에서는 **화면을 좌우로 밀어서** 탭을 넘길 수 있습니다 (왼쪽으로 밀면 다음 탭, 오른쪽으로 밀면 이전 탭). 입력칸·옆으로 밀리는 표·자산 추이 그래프 위에서는 넘어가지 않습니다.

### 홈 (대시보드)
- **총 자산** 큰 숫자, 지난달 기록 대비 변화, 최근 12개월 추이선
- **자산 구성:** 자산군별 비중 막대와 금액
- **한눈에 보기:** 총 손익, 연 예상 배당, 이번 달 가계부 잔액(저축률), 가상자산 비중
- **큰 종목 TOP 5:** 금융자산·가상자산을 합쳐 평가금액이 큰 순서
- "자세히" 버튼으로 해당 탭으로 이동

### 가계부
- 수입/지출 입력: 날짜, 금액, 구분, 카테고리, 메모
  - 지출: 식비, 교통, 주거, 쇼핑, 기타 / 수입: 월급, 기타
- ◀ ▶ 로 달 이동, 그 달의 내역(최신순)과 총수입·총지출·잔액
- 내역 수정·삭제
- **카테고리별 지출:** 그 달 지출을 카테고리별 막대로, 지난달 대비 ▲▼ 표시

### 금융자산
- **전체 자산:** 금융자산 + 가상자산 합계, 총 손익, 자산군별 비중, 이번 달 가계부 요약
- **자산 추이:** 매달 총 자산을 **자동 기록**(이번 달 기록은 자산이 바뀔 때마다 갱신), 선 그래프(누르거나 끌면 그달 값)와 기록 표
  - **지난달 기록 직접 추가·수정:** 앱을 쓰기 전 달의 자산을 넣거나 잘못된 달을 고칠 수 있음 (직접 넣은 기록은 "직접" 표시). 이번 달과 앞으로 올 달은 직접 입력할 수 없음
- **포트폴리오 요약:** 총 평가금액, 총 손익, 수익률, 종류별 비중
- **예상 배당:** 연간·월평균 배당금, 배당수익률, 세후 추정(15.4%), 배당 종목 목록
  - **월별 배당 그래프:** 1~12월 막대, 누르면 그달 들어오는 종목별 금액
- **종목 입력:** 종목명, 종류(국내주식/해외주식/ETF/채권/예적금/현금/기타), 수량, 평균 매입가, 현재가, 주당 연간 배당금
  - 예적금·현금은 수량 1, 매입가와 현재가에 잔액을 넣습니다.
  - 현재가는 직접 입력합니다. 가끔 증권 앱을 보고 **수정**으로 고쳐 주세요.
  - 배당금을 넣으면 **배당 지급월**을 고릅니다 (월배당/분기/반기/연 1회 버튼 또는 1~12월 체크). 지급월이 없는 예전 종목은 12월 지급으로 계산합니다.
- **보유 종목:** 평가금액 순, 종목별 손익·수익률·비중, 수정·삭제

### 가상자산
- 코인명, **심볼**(예: BTC), 수량(소수점 가능), 평균 매입가, 현재가, 보관처
- **시세 불러오기:** 심볼이 있는 코인의 현재가를 원화 시세로 한 번에 갱신
  - **업비트 → 빗썸 → 코인게코** 순서로 시도하고, 앞에서 못 가져온 코인만 다음 곳에서 찾습니다.
  - 결과 안내에 어디서 몇 개를 가져왔는지, 접속이 안 된 곳이 어디인지 표시됩니다.
  - 코인게코 가격은 세계 평균을 원화로 바꾼 값이라 국내 거래소 가격과 조금 다를 수 있습니다.
  - 시세 서비스에는 코인 심볼만 보내고 보유량·금액은 보내지 않습니다.
  - 심볼 칸이 비어 있으면 코인명 속 영어 대문자(예: "이더리움 ETH"의 ETH)를 씁니다.
- 총 평가금액, 손익, 수익률, 코인별 비중 (8번째 코인부터는 "기타"로 묶음)

### 시나리오
- **가격 변동 시나리오:** 자산군별 변동률(%)을 넣으면 총 자산이 어떻게 바뀌는지 바로 계산
  - 예시 버튼(폭락장/조정장/상승장), 자산군별 결과 표
  - **종목별로 따로 정하기:** 특정 종목·코인만 다른 변동률 (빈칸이면 자산군 값)
  - 이름을 붙여 저장하고 여러 개를 비교 (지금 자산 기준으로 다시 계산됨)
- **미래 적립 시뮬레이션:** 시작 금액 + 매월 투자금으로 N년 뒤 금액을 비관/기본/낙관 수익률로 비교
  - "현재 자산", "가계부 평균" 버튼으로 내 데이터를 불러올 수 있음
  - 배당 재투자 여부, 연도별 표

> 시나리오와 예상 배당은 입력한 가정으로 계산한 **추정치**입니다. 실제 수익을 보장하지 않으며 세금·수수료·물가는 대부분 반영하지 않았습니다.

## 데이터 저장과 백업 (꼭 읽어 주세요)

- 데이터는 브라우저의 **localStorage**에만 저장되고, 인터넷으로 어디에도 전송되지 않습니다.
- **브라우저마다, 기기마다 따로 저장됩니다.** (PC와 휴대폰의 데이터는 서로 보이지 않음)
- 브라우저의 "방문 기록 및 웹사이트 데이터 지우기"를 하면 **데이터가 지워집니다.**
- 그래서 페이지 맨 아래 **데이터 백업**을 가끔 해 두세요.
  - **내보내기:** 가계부·금융자산·가상자산·시나리오·자산 기록·시뮬레이션 설정을 `household-backup-날짜.json` 파일 하나로 저장
  - **불러오기:** 그 파일을 고르면 확인 후 데이터를 되살림 (지금 데이터는 백업 내용으로 바뀜)
  - 다른 기기로 옮길 때도 같은 방법을 씁니다.
  - 30일 넘게 백업하지 않으면 빨간 글씨로 알려 줍니다.

## 파일 구조

```
index.html    화면 구조 (탭 5개 + 맨 아래 백업)
style.css     디자인과 모바일 대응
common.js     공통 도구: 저장/불러오기, 금액 표시, 비중 막대, 탭 전환
app.js        가계부 탭
assets.js     금융자산 탭 (포트폴리오, 배당)
crypto.js     가상자산 탭
networth.js   전체 자산 요약 (금융자산 탭 맨 위)
history.js    자산 추이 자동 기록 + 선 그래프
dashboard.js  홈(대시보드)
scenario.js   가격 변동 시나리오
simulate.js   미래 적립 시뮬레이션
backup.js     데이터 백업 (내보내기/불러오기)
```

`index.html`에서 **위 순서대로** 불러옵니다. 뒤에 있는 파일이 앞 파일의 함수를 쓰기 때문에 순서가 중요합니다.

### 코드의 기본 규칙

- **흐름:** 데이터 배열을 바꾼다 → `saveList()`로 저장 → 화면을 다시 그린다(`render…()`)
- **탭끼리 연결:** `saveList()`가 저장할 때마다 `data-saved` 신호를 보내고, 전체 자산·시나리오가 그 신호를 듣고 다시 계산합니다.
- **이름 규칙:** 모든 JS 파일이 이름을 함께 쓰므로, 파일마다 앞에 붙이는 말을 정해 겹치지 않게 합니다.
  (`asset~`, `crypto~`, `networth~`, `history~`, `dash~`, `scenario~`, `sim~`, `backup~`)
- **각 파일 안의 순서:** 1. 상수 → 2. 저장/불러오기 → 3. 계산 → 4. 화면 그리기 → 5. 이벤트 처리 → 시작

### localStorage에 저장되는 이름

| 이름 | 내용 |
|---|---|
| `household-entries` | 가계부 내역 |
| `household-assets` | 금융자산 종목 |
| `household-crypto` | 가상자산 |
| `household-scenarios` | 저장한 시나리오 |
| `household-history` | 월별 자산 기록 |
| `household-sim-settings` | 시뮬레이션 입력값 |
| `household-crypto-price-updated` | 마지막 시세 갱신 시각 |
| `household-last-backup` | 마지막 내보내기 날짜 |

## 고칠 때 알아 두면 좋은 것

- **카테고리 바꾸기:** `app.js` 맨 위 `CATEGORIES`
- **자산 종류 바꾸기:** `assets.js`의 `ASSET_KINDS`와 `index.html`의 종류 `<option>` (저장용 영어 이름은 바꾸지 말 것)
- **색 바꾸기:** `style.css` 맨 위 `:root`
  - 수익/손실 색: `--up`(빨강), `--down`(파랑)
- **시나리오 예시 바꾸기:** `scenario.js`의 `SCENARIO_PRESETS`
- **CSS나 JS를 고친 뒤에는** `index.html`의 `?v=숫자`를 하나 올려 주세요. 그래야 휴대폰에서 예전 파일 대신 새 파일을 받아 옵니다.
- `main`에 올리면 1~2분 뒤 GitHub Pages 사이트에 자동으로 반영됩니다.
